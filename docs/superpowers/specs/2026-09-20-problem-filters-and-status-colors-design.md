# 题库筛选与答题状态配色设计

## 目标

- 将题型和知识点筛选从平铺标签改为紧凑的单选下拉框。
- 将难度筛选改为三个可点击图标，并放在筛选栏最右侧。
- 为两套主题分别调整答对、答错配色，避免不协调的固定绿/红组合。
- 保留文字和图标表达状态，颜色不作为唯一信息。

## 筛选栏

题型使用原生单选 `<select>`，选项包括“全部题型”和五种题型。知识点使用原生单选 `<select>`，选项包括“全部知识点”和接口返回的知识点。选择变化后复用现有题库刷新流程，不新增 API。

难度区通过 `margin-left: auto` 放在筛选栏最右侧，提供三个带文字提示的按钮：

- 入门：单个基础几何图形。
- 进阶：两个叠加或递进图形。
- 挑战：三个层级更丰富的图形。

图标按钮必须带可见文字或 `aria-label`，选中状态同时使用背景、边框和 `aria-pressed` 表达。再次点击当前难度可清除筛选。窄屏允许整个筛选栏换行，难度区保持为一个不可拆散的按钮组。

## 状态配色

采用主题自适应方案：

对错两个语义色必须都落在该主题自己的色系内，跨色系借色（暖主题里的靛蓝、冷主题里的琥珀）会让界面看起来像两套皮肤混在一起。

| 主题 | 正确 实心 / 底 / 文字 | 错误 实心 / 底 / 文字 |
| --- | --- | --- |
| 温暖柔和 | 橄榄苔绿 `#687A38` / `#F3F2E4` / `#55632C` | 赭红 `#A8503C` / `#F9EBE7` / `#8E4030` |
| 炫酷高级 | 松青绿 `#2A7A6B` / `#E6F2EF` / `#1E6154` | 莓红 `#A8435B` / `#FAEAEE` / `#8C3449` |

实心色要承载选项键位的白色文字，所以四个实心色对白字的对比度都保持在 4.5:1 以上；文字色对各自浅底都在 5.8:1 以上。

状态卡、选项边框、选项键位和列表状态徽章统一复用主题变量。结果标题继续显示“回答正确”“回答错误”；客观题选项继续显示 ✓/✗ 或正确答案标记，满足 WCAG 1.4.1“不只依赖颜色传达信息”的要求。

部分正确沿用主题的次强调色，不扩大本次范围。

## 数据与交互

- 题型下拉值映射到现有 `S.filter.types`，但只保存零个或一个值，以保持现有请求参数生成逻辑。
- 知识点下拉值映射到现有 `S.filter.tagId`。
- 难度按钮继续映射到现有 `S.filter.difficulty`。
- 任一筛选变化后调用现有 `refreshList()`。
- 后端接口和数据模型不变。

## 验证

- 自动化测试验证静态页面包含两个下拉框和三个难度按钮。
- JavaScript 语法检查确保脚本可解析。
- Maven 测试确保后端和静态资源集成测试不回归。
- 浏览器人工检查两套主题、下拉筛选、难度选择、正确/错误结果及窄屏换行效果。

## 范围外

- 不实现多选题型下拉。
- 不改“我的练习”里的错题筛选。
- 不引入第三方下拉框、图标库或颜色库。
